# Dependencies and redistribution

Only newly written MATLAB template source and documentation are included.
No original experiment files, recorded data, copied utility libraries, SDKs,
compiled binaries, media, device drivers, or third-party application installers
are distributed. Gaussian images are computed mathematically at runtime.

Install MATLAB and [Psychtoolbox](https://psychtoolbox.org/download) separately.
They retain their own terms; this repository's MIT license covers only this
repository's template code and documentation. It does not grant rights to
MATLAB, Psychtoolbox, or their dependencies. No additional MATLAB toolbox is
intentionally required. These templates do not claim that dependencies are
license-free or free of charge.

API references: [Screen Flip](https://psychtoolbox.org/docs/Screen-Flip),
[MakeTexture](https://psychtoolbox.org/docs/Screen-MakeTexture),
[KbEventGet](https://psychtoolbox.org/docs/KbEventGet).
